Анализ пользовательских отзывов

Система анализирует отзывы и готовит ответы клиентам. 
Вход: отзыв на русском
Выход: JSON с тональностью (sentiment), проблемами (problems) и ответом (reply)

Архитектура

Модель OpenRouter: nvidia/nemotron-3.5-super-vl:free.
One-shot: один запрос на анализ и ответ.
Workflow (Sequential): отзыв > LLM-анализ > LLM-ответ > JSON. Второй вызов использует найденные тональность и проблемы, поэтому этапы выполняются последовательно.

Запуск

Нужен Python 3.10+
Скопировать .env.example в .env и указать OPENROUTER_API_KEY

python -m pip install -r requirements.txt
python main.py "Товар хороший, но доставка задержалась."
python main.py --workflow "Товар хороший, но доставка задержалась."
python main.py --test

Результаты и выводы

10 тестовых отзывов, включая сарказм, отрицание и инструкцию внутри отзыва. 
Результаты: results.json. Качество - accuracy тональности; проблемы и ответы проверены вручную.

Результаты (One-shot / Workflow):
Успешные выполнения: 100% / 100%
Accuracy тональности: 90% / 90%
Среднее время, с: 1.961 / 2.209
Среднее число вызовов: 1 / 2
Средний расход токенов: 271 / 393

В примере 2 One-shot предлагает гарантийное оформление без сведений о гарантии, Workflow просто направляет в поддержку

Workflow не улучшил accuracy и потребовал больше времени и токенов. Для этой задачи выбрал бы One-shot. Основные ошибки: неверная трактовка сарказма, пропуск жалоб и выдуманные сведения. Проверка JSON их не выявляет.

Ограничения: 10 примеров и один прогон
